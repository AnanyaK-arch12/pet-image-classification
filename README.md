# Pet Image Classification

A machine learning project exploring image classification
to recognize pet images using Python and Jupyter Notebook.

## Project Overview

This project uses a Jupyter Notebook to explore pet image
classification techniques.

## Technologies Used

- Python
- Jupyter Notebook
- Machine Learning

## Project Structure

- `pet classifier.ipynb` - Notebook containing the project code.
- `images/` - Dataset images (stored locally, not included in this repository).

## Dataset

The image dataset is not included in this repository
because of its large size.

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Obtain the dataset and configure its path in the notebook.
4. Open the notebook in Jupyter and run the cells.
